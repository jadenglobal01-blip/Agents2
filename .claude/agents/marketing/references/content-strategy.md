# 콘텐츠 전략 레퍼런스

`marketing.md`의 콘텐츠 전략 섹션에서 참조하는 상세 프레임워크 모음.

## Searchable vs Shareable

- **Searchable**: 검색 의도에 맞춤, 키워드 타겟팅, 포괄적 커버리지. 예 — 유즈케이스 콘텐츠,
  허브 앤 스포크(허브 페이지 + 하위 스포크 아티클), 템플릿 라이브러리.
- **Shareable**: 참신한 인사이트, 대담한(contrarian) 주장, 스토리텔링. 예 — 사고 리더십,
  데이터 기반 콘텐츠(자체 제품 데이터/공개 데이터/자체 리서치), 전문가 라운드업(15-30명),
  사례 연구(문제→해결→결과→교훈 구조).

기본 캘린더 배분(고정 규칙 아님, 시작점): **60% Searchable / 30% Shareable / 10% 실험**.

## 콘텐츠 필러 & 토픽 클러스터

필러를 정하는 4가지 관점: 제품 중심 / 오디언스 중심 / 검색 중심 / 경쟁사 중심.
구조: 허브(필러 페이지) → 서브토픽 클러스터 → 개별 아티클(허브로 내부링크).

## 구매 여정 단계별 키워드

| 단계 | 키워드 성격 |
|---|---|
| Awareness | 문제/증상 키워드 ("왜 ~한가") |
| Consideration | 솔루션 비교 키워드 ("~ vs ~", "best ~") |
| Decision | 제품/브랜드 키워드 ("~ pricing", "~ alternative") |
| Implementation | 사용법 키워드 ("how to set up ~") |

## 콘텐츠 아이디어 소싱 6채널

1. 키워드 데이터 (볼륨/난이도/구매단계/우선순위 테이블화)
2. 고객 콜/통화 녹취
3. 설문 응답
4. 포럼 리서치 (Reddit/Quora/Indie Hackers/HN/Product Hunt 검색 연산자 활용)
5. 경쟁사 분석 (site: 검색 연산자로 경쟁사가 다루는 주제 파악)
6. 세일즈/서포트 팀 피드백

## 우선순위 스코어링 (가중치)

- 고객 임팩트 40%
- 콘텐츠-마켓 핏 30%
- 검색 잠재력 20%
- 리소스 요구량 10% (낮을수록 유리)

## 배포 전략: Create Once, Distribute Twice

플래그십 콘텐츠 1개를 만들고 여러 채널에 맞게 재가공(트랜스크립트, 인용구, 클립, 요약 등)한다.
**ORB 프레임워크**: Borrowed(빌린 채널, 발견 단계) → Rented(임대 채널, 참여 단계) →
Owned(소유 채널, 전환 단계). 흔한 실패 패턴: (1) 스프레이 앤 프레이(전방위 살포 후 방치),
(2) 플랫폼 의존(알고리즘 변경에 취약), (3) 소유권 역설(노력의 대부분을 통제 불가능한
채널에 쏟는 것).

## 포맷별 실행 기준

- 블로그 글: 제목 후보 10개 뽑고 선택, 최소 5회 편집 패스
- 롱폼 가이드: 스포크보다 허브(구조)를 먼저 설계
- 영상: 훅(첫 3-5초) 스크립트를 가장 먼저, 촬영 시점에 재가공 소스도 함께 확보
- 팟캐스트: 발행 후 트랜스크립트/인용/클립/요약으로 쪼개질 것을 전제로 설계
- 이메일: 발송당 하나의 아이디어만

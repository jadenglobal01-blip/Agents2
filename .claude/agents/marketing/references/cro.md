# CRO(전환율 최적화) 레퍼런스

`marketing.md`의 CRO 섹션에서 참조하는 상세 진단 프레임워크 모음.

## 7단계 진단 프레임워크 (임팩트 순)

1. **가치 제안 명확성** (임팩트 최고) — 5초 테스트: 방문자가 5초 안에 "무엇을, 누구를 위해,
   왜 다른지"를 알 수 있는가. 흔한 문제: 기능 위주 설명, 너무 막연하거나 재치 위주, 모든 것을
   말하려다 아무것도 명확하지 않음.
2. **헤드라인 효과** — 결과 중심, 구체성, 사회적 증거 중 하나 이상을 담고 있는가.
3. **CTA 배치·문구·위계** — 1차/2차 CTA 구분이 명확한가, 문구가 행동 동사+구체적 대상인가.
4. **시각적 위계 & 스캔 가능성** — 방문자가 훑어봤을 때(스캔) 핵심 메시지가 눈에 들어오는가.
5. **신뢰 신호 & 사회적 증거** — 로고, 후기, 사례 스니펫, 리뷰 점수, 보안 배지. CTA 근처와
   혜택 주장 직후에 배치했는가.
6. **반론 처리** — 가격, 적합성, 도입 난이도, "효과 없으면 어떡하지" 같은 흔한 반론을
   FAQ/보증/비교표/투명성으로 해소하는가.
7. **마찰 지점** — 폼 필드 수, 불명확한 다음 단계, 헷갈리는 내비게이션, 불필요한 필수 입력,
   모바일 이슈, 로딩 속도.

## 페이지 유형별 체크포인트

- **홈페이지**: 방문자 세그먼트별 분기 경로가 명확한가
- **랜딩페이지**: 광고/캠페인 메시지와 페이지 메시지가 일치하는가
- **가격 페이지**: 플랜 비교가 "선택 마찰"을 만들지 않는가, 추천 플랜이 시각적으로 강조되는가
- **기능 페이지**: 기능 → 결과 연결이 CTA까지 이어지는가
- **블로그 글**: 글 내 CTA가 글의 의도(정보 탐색)와 자연스럽게 맞물리는가

## 폼 최적화

- 꼭 필요한 필드만 남기기 (필드 하나 줄일 때마다 완료율 상승 경향)
- 긴 폼은 다단계로 쪼개고 진행률 표시
- 에러 메시지는 입력 즉시, 구체적으로("이메일 형식이 올바르지 않습니다" 등)

## 실험 아이디어 카테고리

히어로 섹션(헤드라인/이미지), 신뢰 신호 배치, 가격 표시 방식(월/연 전환, 앵커링),
폼(필드 수/순서), 내비게이션/UX 흐름.

## 산출물 포맷

CRO 분석 결과는 다음 4부분으로 구성:
1. **Quick Wins** — 즉시 적용 가능한 낮은 리스크 변경
2. **High-Impact Changes** — 구조적이지만 임팩트 큰 변경
3. **Test Ideas** — A/B 테스트로 검증이 필요한 가설
4. **Copy Alternatives** — 헤드라인/CTA 등 요소별 대안 2-3개 + 근거

# 콜드 이메일 레퍼런스

`marketing.md`의 콜드 이메일 섹션에서 참조하는 상세 프레임워크 모음.

## 개인화 4단계

1. **레벨 0 (금지)**: {{FirstName}} 같은 스팸형 자동 삽입만 있는 것 — 사용 금지.
2. **레벨 1**: 회사/직함 정도만 언급 (약한 개인화).
3. **레벨 2**: 공개 정보(채용 공고, 펀딩 뉴스, 기술 스택, LinkedIn 활동)를 근거로 한 관찰.
4. **레벨 3**: 그 관찰이 상대방이 겪고 있을 **구체적 문제**와 논리적으로 연결됨.

테스트: 개인화 도입부를 지웠을 때도 이메일이 말이 되면, 그 개인화는 제 역할을 못 하고 있는 것.

## 이메일 구조 프레임워크 (4종, 상황에 따라 선택)

1. **관찰 → 문제 → 증거 → 요청** (Observation → Problem → Proof → Ask)
2. **질문 → 가치 → 요청** (Question → Value → Ask)
3. **트리거 이벤트 → 인사이트 → 요청** (Trigger → Insight → Ask)
4. **스토리 → 연결 → 요청** (Story → Bridge → Ask)

## 제목줄 규칙

- 2-4단어, 소문자, 구두점/기호 트릭 없음
- 광고처럼 보이지 않고 동료가 보낸 것처럼 보여야 함
- 긴급성 유발 문구, 이모지, 이름 삽입 금지

## 후속 시퀀스

- 총 3-5통, 간격은 점점 넓어지게 (예: 3일 → 5일 → 7일 → 10일)
- 매 통마다 **새로운 각도**를 하나씩 추가 (같은 말 반복 금지)
- 마지막 통은 "브레이크업 이메일"(정중하게 마무리, 대신 낮은 부담의 대안 제시)

## 발송 전 품질 체크리스트

- [ ] 소리 내어 읽었을 때 사람이 쓴 것처럼 들리는가
- [ ] 내가 받는다면 답장하고 싶은가
- [ ] 발신자가 아니라 수신자에게 도움이 되는 내용인가
- [ ] 개인화가 실제 문제와 연결되어 있는가
- [ ] 요청이 하나이고, 마찰이 낮은가(미팅 요청보다 "관심 있으면 답장 주세요" 같은 저마찰 CTA 선호)

## 피해야 할 것

일반적인 오프닝("I hope this email finds you well"), 전문용어("leverage", "synergy"),
기능 나열식 피치, HTML/이미지/다중 링크, 가짜 Re:/Fwd: 제목, 스팸성 {{FirstName}} 남발,
첫 접촉에서 바로 30분 미팅 요청, "그냥 확인차 연락드립니다" 류의 의미 없는 후속.
